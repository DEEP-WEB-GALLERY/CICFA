# usecases/ — casos de uso
> *English summary:* a use case is the lab notebook of one possible operation before it exists — hypotheses, comparisons, an experiment design. Never decisions. Spanish by convention.

```
QUÉ            investigación antes de una operación: hipótesis, variantes, un ensayo. no es un encargo ni una operación.
ID             lo da Boris (`B0.1`). no cambia. la letra no hereda de ninguna versión anterior del programa.
REV / ENSAYOS  cada documento lleva `rev: 01, 02…` en su frontmatter · un ensayo ejecutado se registra como `ensayo-0`, `ensayo-1`… nunca como versión del OS ni del caso.
LENGUA         español rioplatense; una línea de resumen en inglés por documento.
INSTITUCIÓN    agnóstico por construcción: ningún archivo público nombra una institución destinataria.
```

## Qué investiga

Si el circuito encargo → ejecución → evidencia → evaluación → distribución puede ser la obra. No un bounty anunciado en una plataforma: el bounty como forma.

La plataforma no es el soporte donde se anuncia una obra: su dinámica de encargo, ejecución, evaluación y distribución económica es la obra.

Este caso de uso no reduce CICFA a una plataforma convencional de investigación ni a un servicio de auditoría.

Institución destinataria: `[INSTITUCIÓN DESTINATARIA — por definir]`. No se confirmó ninguna.

Ninguna variante está aprobada. «El reverso del museo» es una alternativa conceptual propuesta por un interlocutor, no una dirección artística decidida.
